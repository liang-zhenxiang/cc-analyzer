# Round FF · 第四批十功能「实验室」· UI/UX 设计规格

**一句话定位**：实验室不是又一组 KPI，而是十台量不同的仪器并排放在同一张工作台上——同一份本机日志，用**形状、密度、结构与节奏**回答「这段时间到底是什么样子」。前十功能回答「多少、什么时候、哪一次」，这一批回答「看起来像什么」。

作者：liangzhenxiang。日期：2026-10-29。分支 `feat/v034-batch-ten-4`。本文只写规格，不含实现代码。

### 0.3 每张卡的数据来源与口径

**全部来自已有的 `inputs` / `range` / `toolCalls`，零新增后端命令。** 但有三处口径必须写死在纯函数层，不能在组件里各算一遍：

| 卡 | 输入 | 口径 | 已知缺口（必须显式声明） |
| --- | --- | --- | --- |
| F1 | `session.records` 的起止时间、`usage`、`model` | 会话起点 = 窗口内第一条记录；token = 窗口内四类之和（与 KPI 同口径） | 跨窗口边界的会话只画窗口内那一段 |
| F2 | 每条 `record.usage` + `record.model` + `timestamp` | 成本 = `estimateCost` 按记录模型估算，按本地小时落格 | 未定价模型的记录整格不计，报出受影响小时数 |
| F3 | `toolCalls` 的 `durationMs` / `key` / `timestamp` / `sidechain` | 含子 agent（那是真实耗时），只累计**已配对工具结果**的耗时 | 未配对调用的耗时未知 ≠ 0，单独报数 |
| F4 | 同 F2 + 窗口内最便宜已定价模型 | 假设推演，不写回任何设置 | 只对已定价的调用建模 |
| F5 | 每条 `record.usage` + `model` | 与页面成本读数**同一份 records（主链）**，不含 `sidechainMessages` | 无定价模型的调用不参与排名，报数 |
| F6 | `toolCalls` 的 `key`，按会话分组 | 同会话内都出现过即共现；含子 agent（与工具普查同口径） | 共现不等于因果 |
| F7 | 扫描同趟产出的 `fileFacts`（Read/Edit/Write/NotebookEdit 路径，含子 agent） | 复用 `extractFileActivities` 的既有口径 | Bash 间接改文件看不见（见 §7.3 数据通道） |
| F8 | `records` 的 `kind` + `timestamp` | 最近一个有活动的自然日；只画 user / assistant / tool | wait / system 不是对话节奏，不画 |
| F9 | 本周 `records.usage` + `usePlan().weeklyLimitTokens` | **自然周（周一起）**，与页头「近 N 天」正交 | 未设预算就不画终点、不给百分比 |
| F10 | `kind === "user"` 且非 `compactSummary` / `isSynthetic` / `isInterrupt` | 间隔 = 与上一条用户消息之差；字数 = Unicode 码点数 | 0 字不计入；少于 5 秒、超过 24 小时或 1 万字的点不画，计数写脚注 |

> **窗口边界只允许有一个实现。** 现在 `aggregateRange` 自己算 `startTs`，实验室若再写一遍必然漂移。实现时先把这段抽成 `rangeWindow(days, now): { startTs, now }` 并由 `aggregateRange` 与 Lab 共用；Lab 不得自行 `Date.now()` 定义窗口。Lab 的 `now` 取挂载时刻并保持稳定（与 `calendarNow` / `milestonesNow` 同一取舍），避免十张卡每 30 秒重算。

## 1 实验室整体版面

### 1.1 挂载：第 5 个子视图，不是新页面

- `UsageView` 增加 `"lab"`；`VIEW_ITEMS` 追加 `{ value: "lab", label: "实验室" }`，**排在「年报」之后**。
  - 理由：前四档分别是「这一窗口 / 这一年」的读法，实验室是「换十种读法看同一窗口」——它是读法的集合，理应最后。
- `readStoredView` 白名单同步加 `lab`；`VIEW_KEY` 持久化规则不变。
- **区间控件在实验档保留**：10 张卡里 9 张吃「近 N 天」；唯一例外 F9 在脚注声明「自然周口径，与页头区间无关」。不要重演里程碑/年报那种「控件不起作用」的坑——跑道是例外，就在它自己卡里说清楚。
- **不渲染「导出快照」**：本轮不给实验室做 HTML 快照。按钮仍只在 `usage` 档出现。
- 进度行文案扩展为：`近 ${days} 天内 ${range.kpi.sessions} 个会话纳入统计 · 10 个视角`；`skipped` 提示照旧拼接。

### 1.2 页头：两行，控件不复制

```
┌ 行 1（现有 .header，一行不改结构）──────────────────────────────────┐
│ [用量|里程碑|错误|年报|实验室] [近7天|近30天|近90天]   ◉ 进度文本  │
└────────────────────────────────────────────────────────────────────┘
┌ 行 2（新增 .labIntro）─────────────────────────────────────────────┐
│ 实验室                                             近 30 天 · 10 个视角 │
│ 十个视角读同一份本机日志：形状、密度、极端值与前瞻——全部现算，不出本机。 │
└────────────────────────────────────────────────────────────────────┘
```

- 行 1 完全复用现有 `.header`：**窗口选择器只有这一份实例**。行 2 右侧的「近 30 天」是**文本口径声明**（同 `AnnualReportPanel` 的 `.scope`），不是第二个控件——同一状态出现两次控件才是坑。
- 行 2 的标题用 `<h2>`，十张卡用 `<Panel titleAs="h3">`。为此 `Panel.module.css` 需要把 `.header h2` 规则扩成 `.header h2, .header h3`（一行）。若不改，h3 会掉回浏览器默认字号——这是必须一起改的共享原语。
- 行 2 排版：标题 `--fs-md` / 600 / `--lh-md`；说明 `--fs-sm` / `--text-secondary` / `--lh-sm`；右端 scope `--fs-xs` / `--text-tertiary`。整行 `display: flex; justify-content: space-between; align-items: baseline; gap: var(--sp-3); flex-wrap: wrap`。
- 说明文案（定稿）：**「十个视角读同一份本机日志：形状、密度、极端值与前瞻——全部现算，不出本机。」**

### 1.3 卡片网格：12 列，6 行

```css
.labGrid {
  display: grid;
  grid-template-columns: repeat(12, minmax(0, 1fr));
  gap: var(--sp-3);          /* 12，与页面 gap 同一档 */
  align-items: start;        /* 卡高由内容决定，同排不强行等高 */
}
```

排布按**阅读叙事**而不是 Issue 编号。下表「主体高」指图形 / 读数组本身的高度（**不含**脚注、下方列表、40px 表头与 24px 上下内距；整卡高 = 主体高 + 脚注/列表 40–100 + 66）：

| 行 | 卡片 | span（≥1081） | 主体高 @1440 | 为什么在这一格 |
| --- | --- | --- | --- | --- |
| A | F1 会话星系 | 12 | ~434（`viewBox 960×300`） | 全景，必须独占整行 |
| B | F2 成本地形 | 7 | ~331（`720×300`） | 先看「什么时候贵」，紧跟其最贵的一次 |
| B | F5 最贵时刻 | 5 | ~306（DOM：台 138 + 榜 168） | 与地形成对：形态 → 极值 |
| C | F3 工具火焰 | 7 | ~300（DOM：轴 16 + 12 行 ×22 + 图例 18） | 再看「时间花在哪」，然后推演「如果重来」 |
| C | F4 成本沙盘 | 5 | ~334（读数 22 + 滑杆 132 + 瀑布 180） | 与火焰同排，左观察右假设 |
| D | F6 工具生态 | 6 | ~361（`600×320`）+ 3 行共现列表 | 结构一：工具之间 |
| D | F7 文件足迹 | 6 | ~361（`600×320`）+ 3 行共享列表 | 结构二：项目之间 |
| E | F8 对话心跳 | 12 | ~203（`960×140`）+ 读数行 | 一条横向节奏带，独占整行 |
| F | F9 预算跑道 | 5 | ~237（`520×180` + 4 格读数） | 前瞻 |
| F | F10 提示词节奏 | 7 | ~287（`720×260`） | 个人节律，与跑道同排收尾 |

- 十张卡按自身内容自然生长；按上表主体高 + 每卡 40–100px 的脚注/列表 + 66px 卡片骨架估算，整页约 **3000px @1440**（约 3.5 个视口，内容区高 900 − 顶栏 48 = 852）。实验室本来就该是一条可滚动的仪器带，不做「一屏塞完」的压缩，也不用固定行高把图裁掉。
- 卡片跨度用语义类（`.galaxy { grid-column: span 12 }`、`.terrain { grid-column: span 7 }`……），不要写内联 style，也不要复用一个 `.spanN` 数组——一张卡改跨度时应该只改一行。
- **断点**：`max-width: 1080px` 时所有 `.labGrid > * { grid-column: 1 / -1 }`，与页面既有 `.halfPanel` 的断点一致（`UsageOverviewPage.module.css:221`）。不要为实验室另造 1120/1040 这类新断点。

### 1.4 密度与滚动

- 页面是纵向文档流（`.content` 整体滚动），**卡内不出现第二根滚动条**。
- 不设粘性表头、不做分页、不做 hover 展开整卡——十张图同屏并列才是「实验室」的感觉。
- 同一行的两张卡不强行等高：`align-items: start`，矮的那张底部留白由脚注自然收口。视觉高度差控制在 40px 以内（上表已按此调过），超过就说明有一个 viewBox 比例选错了。
- 卡片间距的唯一来源是 `gap`；卡内不再加外边距。脚注统一 `margin: var(--sp-2) 0 0`。

### 1.5 与现有用量页的一致性清单

- 全部用 `Panel` 原语：表头 40px、标题 `--fs-base`/600、body 12px 内距、`--r-md`、`--bg-subtle`、发丝边框、**无阴影、不嵌套卡片**。
- `actions` 槽只放三类东西：**scope 文本**（`42 个会话`）、**来源圆点**（`ProvenanceBadge`）、**一个视图切换**（F3 的耗时/次数）。不塞按钮簇。
- 空态统一 `EmptyState size="inline"`（卡内空间小，`panel` 档会把空态撑成主角），紧跟一行 `--text-tertiary` 的原因说明。
- 脚注写法沿用 `FlowDiagramPanel` / `FingerprintPanel`：`--fs-xs`、`--lh-xs`、`--text-tertiary`，一句话说清「轴是什么、颜色是什么、哪些数不算」。
- 数值一律 `font-variant-numeric: tabular-nums`；时间/金额/计数用 `--font-mono`（与 `.modelValue` 同款）。

## 2 逐卡视觉规格

> 本节按**网格阅读顺序**排列（F1 → F2 → F5 → F3 → F4 → F6 → F7 → F8 → F9 → F10），功能编号 F1–F10 跟 Issue 走。
> 每张卡固定回答八件事：隐喻 / 构图 / 轴与标签 / 颜色 / 交互 / 空态 / 脚注 / 无障碍摘要 + 探针。

### 2.1 F1 会话星系（行 A，span 12）

**隐喻**：项目是十条水平航线，时间从左往右流；每个会话是一颗星，越重越大，颜色是它用的模型。

**构图**：`viewBox 960×300`，`width:100%; height:auto`（沿用既有图表的等比缩放）。
- 绘图区：左 132（泳道名）、右 16、上 20（时间轴）、下 24。泳道数 `L = min(8, 项目数)`，尾部并入「其他 N 个项目」一条中性泳道；泳道高 `(300-20-24)/L`。
- 星：`cx` 由开始时间映射到 `[132, 944]`，`cy` 取泳道中线。半径 `r = 2.2 + 7 × sqrt(tokens / maxTokens)`（最大 9.2）。零 token 的会话画成空心环（`r=2.2`，stroke `--text-faint`），不省略——「开过但没有用量」是事实。
- 同小时连线：同一泳道内、开始时间落在同一小时的**相邻两颗星**之间画 1px `--border-strong` 直线；最多 60 条，超出部分不画并在脚注报数。不做曲线、不做跨泳道连线。
- 重叠：**不加抖动**（抖动会伪造时间）。重叠的星用 1px `--bg-subtle` 描边分隔（`paint-order` 的思路），hover 时提到最前。

**轴与标签**：
- 时间刻度按窗口自适应，复用 SessionGantt 的策略：7 天 → 每天一格；30 天 → 每周一格（周一起）；90 天 → 每月 1 日。标签 `--fs-xs`、`--text-tertiary`、`tabular-nums`。
- 泳道名在左端右对齐，最多 14 个字符，超出省略并以 `<title>` 给全名。
- 不画纵轴刻线；泳道之间不画分隔线（避免十条横线抢注意力），只靠 y 位置区分。

**颜色**（零新增）：
- 模型按 token 排名取前 6：`--chart-1..6`（与「按模型分布」同序同色）。第 7 名及以后统一 `--text-faint`，不进色板循环——**不沿用页面现有的 `index % 6`**：在一张散点里，两个模型撞色会被读成同一个模型。
- 无用量会话：空心 `--text-faint`。
- 网格/轴：`--border`；连线：`--border-strong`；hover 描边：`--ink`。
- 不使用 `--cal-*` / `--cat-*` / 语义色。

**交互**：
- hover 星：`r + 1`、1px `--ink` 描边，`<title>` 给出「项目 · 标题 · 时间 · token · 模型」。过渡只用 `--dur-hover`。
- 点击星 / 键盘：星本身不做焦点目标（SVG 里逐点聚焦会制造几十个 Tab 停靠点）；卡片下方给一张「最重的 5 个会话」可见清单（DOM 行按钮，`--fs-sm`），点击走既有 `onOpenSession`。图形用 `role="img"` + 摘要承担读屏，清单才是可操作层。

**空态与数据不足**：
- 窗口内 0 个会话：`EmptyState inline`「所选范围内没有会话」。
- 1 个会话：照常画轴与星，轴下加一行 `--fs-xs`「本窗口只有 1 个会话」。
- 项目数 > 8：折叠为「其他 N 个项目」，脚注报出被折叠的项目数。
- 全部会话都无 usage：星全为空心环，脚注「这些会话没有用量读数，大小按最小半径画」。

**脚注**：「横轴是开始时间，纵向是项目泳道；星的大小按 token，颜色按模型（与「按模型分布」同一顺序）。同一小时内的相邻会话用细线相连。」

**无障碍摘要**：`role="img"`，`aria-label="会话星系：近 30 天 42 个会话、7 个项目；最大的一颗是 <项目> 的 <标题>（2.1M token）。"`

**探针**：`data-probe="lab-galaxy"`。

### 2.2 F2 成本地形（行 B，span 7）

**隐喻**：一周七天 × 二十四小时是一张等高线地图；山谷是省钱的时候，山脊是烧钱的时候。

**构图**：`viewBox 720×300`。

### 2.5 F4 成本沙盘（行 C，span 5）

**隐喻**：三根推杆 + 一张瀑布图——把「如果当时……会怎样」拆成可以看见的台阶。

**构图**（滑杆是 DOM，瀑布是 SVG）：
- 三根滑杆，每行 44px：左标签（`--fs-sm`/`--text-secondary`）、中 `<input type="range">`（`accent-color` 已全局设为 `--accent`）、右读数（`--font-mono`/`--fs-sm`/tabular）。
  1. **目标缓存命中率**：下界 = 当前命中率，上界 95%；当前已 ≥95% 时该杆禁用并标「已在上限」。
  2. **便宜模型接管比例**：0–100% 的调用量按本窗口**最便宜的已定价模型**重算（四类 token 同比例）。
  3. **输出削减**：0–50%。
- **初始值不是 0**：目标命中率 = `min(当前 + 20 个百分点, 95%)`、接管比例 25%、输出削减 15%。全 0 会让瀑布只剩两根等高的柱子，整张卡看起来像坏了；给一组温和的演示假设，并让每个数字都可调、都标「假设」。重置回到这组初始值（不是归零）。
- 瀑布图：5 根竖柱、高 180，`viewBox 520×180`：现状 / −缓存 / −换模 / −输出 / 假设成本。柱宽 56，间距 24。
  - **现状柱中性**：`--bg-inset` 填充 + 1px `--border-strong`（这是「读出来的数」）。
  - **四个推演柱一律 `--chart-1-soft` + 1px `--chart-1`**（不按「好/坏」上色）。减少用「悬空柱」画（从上一级顶落到新一级顶），差值标「−$1.80」；最终柱落地。

- 顶部一行读数：现状 $12.40 → 假设 $8.10（`--fs-md`/600，右端）。
- `actions`：`重置`（`Button` secondary，24px 高）。

**颜色**（零新增）：
- 只用 `--chart-1` / `--chart-1-soft` / `--bg-inset` / `--border-strong` / `--text`。
- **不引入绿色「省钱」**：`--success` 的语义是「确定的读数」，不是「好事」；把节约涂绿会让读者以为那是承诺。
- 差值靠符号 + 柱形方向表达，颜色只区分「实测 vs 假设」。

**交互**：
- 滑杆原生键盘（方向键、Home/End）；每个 `aria-valuetext` 写成「目标缓存命中率 60%」这种完整句。
- 数值实时更新；**不持久化**，离开页面即回到初始假设——沙盘不是设置，不该悄悄带着上次的假设影响下一次阅读。
- 重置按钮回到初始假设（见上），不回零。

**空态与数据不足**：
- 窗口内没有可定价的用量：`EmptyState inline`「所选范围内没有可建模的消耗」，**不渲染滑杆**（摆一根推不动的杆比没有更坏）。
- 只有一个杠杆有作用：五根柱照样全画，差值为 0 的柱子标「0」，不省略。
- 当前成本为 0 但有调用：按空态处理（没有可省的基线）。

**脚注**：「全部是假设推演，不写回任何设置；顺序为缓存 → 换模 → 输出。缓存增益按目标命中率重算 cacheRead 与 cacheCreation，换模按本窗口最便宜的已定价模型折算，结果仍是估算。」

**来源**：`ProvenanceBadge provenance="estimated"`。

**无障碍摘要**：`aria-label="成本沙盘：当前 $12.40；把缓存命中率提到 60%、30% 调用改用便宜模型、输出削减 20% 后，假设成本 $8.10。"`

### 2.6 F6 工具生态（行 D，span 6）

**隐喻**：工具不是孤立的——同一段工作里一起出现的工具之间有边，边的粗细就是它们一起干活的次数。

**构图**：`viewBox 600×320`。
- 节点：按调用次数取前 8 种工具，放在圆心 `(300,160)`、半径 110 的圆上，角度从 -90° 起等分（**确定性布局，不做力导向**——每次打开位置都该一样）。
- 节点半径 `6 + 8 × sqrt(calls / maxCalls)`（6–14）。
- 边：只画**在 ≥2 个会话中同现**的工具对，三次贝塞尔曲线（`ribbon` 同款），线宽 `0.8 + 3.2 × (共现会话数 / 最大值)`，stroke `--text-tertiary`，`stroke-opacity: 0.55`。无箭头（共现是对称的）。
- 标签：节点外侧，按 `cos` 决定 `text-anchor`；`--fs-xs` / `--text-secondary`；名称超 10 字符省略。**标签常显**，不靠 hover。
- 图下方「最强共现」3 行 DOM 列表：`Bash ↔ Read · 14 个会话`（同时是键盘/读屏的等价物）。

**颜色**（零新增）：
- 节点：`--chart-1-soft` 填充 + 1.5px `--chart-1` 描边；调用最多的枢纽节点描边 2px。
- 边：`--text-tertiary`（这是**承载数据的线**，需要 3:1 以上；`--border-strong` 的 14% 半透明在深色下不够）。结构网格才用 `--border`。
- **工具类型（内置/技能/MCP/子 agent）不用颜色区分**：`--cat-*` 已被「记录类别」占满，借来标工具类型会让两个维度一起失效。类型写在标签后缀或 title 里（如 `Bash`、`Skill: lint`、`mcp:fs`）。

**交互**：

- 点击节点无动作（本轮没有「按工具下钻」的数据通道），因此指针样式保持 `default`，避免假装可点。

**空态与数据不足**：
- 工具种类 < 2，或没有任何一对在 ≥2 个会话同现：`EmptyState inline`「工具之间还没有重复共现」，下一行 `--fs-xs` 说明「本窗口有 N 种工具、M 个会话；共现需要同一对工具在至少 2 个会话里同时出现」。
- 只有 2 种工具：不画网络，直接画一条边 + 两个节点，读数照常——图形仍在讲同一件事，不硬套圆环。
- 共现对 > 28 条：只画最强的 28 条，脚注报「另有 N 对未画」。

**脚注**：「共现 = 同一会话里都出现过，不代表因果；只画在 ≥2 个会话中重复出现的工具对。MCP 工具按 server 收口，子 agent 的调用计入本会话。」

**无障碍摘要**：`aria-label="工具生态：本窗口 9 种工具；Bash 与 Read 在 14 个会话中共现，是最强的一对。"`

## 3 三个主题下的可读性策略

### 3.1 颜色身份的三条硬规则（本轮唯一的新约定）

1. **系列**（模型 / 项目 / 工具 / 提示词-项目）→ `--chart-1..6`，图例必须在同一张卡内，跨卡不保证同一身份。
2. **时间格里的成本强度** → `--cal-1..4`（与消耗日历同一语义，不另造成本色带）。
3. **对话记录类别** → `--cat-user` / `--cat-compute` / `--cat-direct`（`ReplayView` 已确立的映射）。

其余一律中性：`--text*`、`--border*`、`--bg-inset`、`--bg-active`。语义色 `--success / --warning / --danger` **不出现在任何图形数据上**；成本的不确定性由 `ProvenanceBadge`（`estimated` / `inferred` 圆点）承担，不靠黄色面积。

## 4 无障碍

### 4.1 每个图形 `role="img"` + 一句话摘要

十张卡里 8 张有 SVG（F1、F2、F4 的瀑布、F6、F7、F8、F9、F10）；F3 与 F5 是纯 DOM。统一规则：

- SVG 一律 `role="img"` + `aria-label`，摘要必须是**这一屏最值得读的 2–3 个事实**，不是「一张图」。
- `<title>` 只做补充，绝不作为唯一信息源（`<title>` 对键盘与读屏不可靠）。
- 图上能读到的精确值，必须在 DOM 里有等价物：F1 的「最重 5 个会话」、F5 的榜单、F6 的「最强共现」、F7 的「共享最多的文件」、F8 的读数行、F9 的 4 格读数。F2、F10 没有逐项列表，摘要 + 常显标注已覆盖主干（峰值/中位）。
- 摘要模板：`「<卡的隐喻>：<窗口> <总量>；<极值>；<缺口>。」` 缺口（未定价、未配对、样本不足）必须出现在摘要里，不能只写脚注。

### 4.2 键盘可达

- 页面级：实验室 tab 在 `SegmentedControl` 的 roving tabindex 里，方向键切换，无需额外处理。
- 卡内可操作项**只允许是行按钮或原生控件**：
  - F3 / F5 / F1 清单：整行 `<button>`，`focus-visible` 用 `--focus-ring-inset`（`SessionGanttPanel.module.css:56-59` 同款），避免被卡片裁掉。
  - F4：三根原生 `input[type=range]`，方向键 / Home / End；每个带 `aria-valuetext`；Tab 顺序 = 标签行顺序。
  - F8：`跳到这一天` 是唯一按钮，放在 `actions`，Tab 序在图形之前（DOM 顺序即视觉顺序）。
  - F9：无交互控件；来源圆点不是焦点目标。
- SVG 图形本身**不进入 Tab 序**（不给 20 个点加 `tabindex`）。这是本轮最重要的键盘裁决：可达性靠列表，不靠逐点。
- 焦点环一律走全局 `:focus-visible` 令牌，不写死颜色或宽度。

### 4.3 `prefers-reduced-motion`

- 实验室**不新增任何 `@keyframes`**。F8 尤其不能做「扫描线」或「心电跳动」——那会伪造实时性，且与「安静的仪器」相悖。
- 允许的动效只有 hover/active 过渡，时长 `--dur-hover`（80ms）/ `--dur-state`（140ms），属性限定 `opacity` / `stroke-opacity` / `stroke-width` / `background-color`。
- 全局 `@media (prefers-reduced-motion: reduce)` 已把时长归零（`global.css:38-48`）；因为实验室没有循环动画，归零后所有终态仍是静态可见形态。
- 星点 hover 的 `r+1` 是几何变化，不做 transition（避免「呼吸」感）；只过渡描边透明度。

### 4.4 读屏顺序与语义

- 行 2 的 `h2 实验室` → 十张 `h3` 卡 → 每卡内的 `actions` 文本 → 图形摘要 → 列表/读数 → 脚注。DOM 顺序必须与视觉顺序一致（网格只改列位置，不改 DOM 顺序）。
- 卡片用 `Panel ariaLabel` 暴露为命名 region，e2e 与读屏都能按名字定位。
- 脚注不是「装饰」：它包含口径与缺口，必须留在无障碍树里（不要 `aria-hidden`）。

### 5.3 130% 字号

用 `useFontScale()`（已有钩子）在**数据层**收敛数量，而不是用 CSS 缩放图形：

| --- | --- |
| F1 | 泳道 8 → 5；图例仍 6 色（颜色身份不能砍） |

| F3 | 行 12 → 8；图例可换 3 行 |
| F4 | 滑杆行高 44 → 52（文字变大，控件不缩）；瀑布高度不变 |

## 7 实现约束

### 7.1 纯 SVG / DOM，不引图表库

- 允许：手写 `<svg>`、DOM 网格/绝对定位、`charts/chartPrimitives` 的轴与刻度函数、`Panel` / `Button` / `EmptyState` / `SegmentedControl` / `ProvenanceBadge`。
- 不允许：d3、recharts、visx、任何需要新增依赖的方案；不允许 canvas（截图缩放、高 DPI、WebKit 渲染都会出问题）。
- 复用优先：曲线用 `FlowDiagramPanel` 的 `ribbon()` 思路；刻度用 `buildTicks` 的思路；周标签用 `WEEKDAY_LABELS`；金额/token/日期格式化用 `lib/format`。

### 7.2 动效只用既有节奏

- 只允许 `--dur-hover` / `--dur-state` + `--ease-out` 的过渡；不写新的 `@keyframes`，不写 `animation`。
- 既有 `animations.css` 的三条关键帧（`cca-enter` 浮层进入、`cca-breathe` 骨架呼吸、`cca-heartbeat` 实时脉搏）**本轮一条都不引用**：实验室里没有浮层，也没有「活的」读数。
- `prefers-reduced-motion` 不做特判——全局规则已覆盖，前提是「没有循环动画」。
- 图形出现不做入场动画：十张卡一起淡入会让「仪器面板」变成「PPT」。

### 7.3 数据通道与口径（本轮仅有的架构改动）

1. **抽出 `rangeWindow(days, now)`**：`aggregateRange` 与 Lab 共用窗口边界，禁止第二份实现。
2. **F7 的文件事实（已定）**：`records` 只能看到主链文件调用；`ChangedFilesView` 用的是 `extractFileActivities(parsed)`（含子 agent）。若直接用 `records` 推导，两处会对「这个项目动过哪些文件」给出不同答案。**决定**：按 `toolCalls` 的先例，在扫描时同趟产出 `fileFacts` 挂到 `UsageSessionInput`（**不新增命令，只在既有扫描里多返回一个字段**），Lab 复用同一份 `extractFileActivities`。若评审否决这个字段，必须在 F7 脚注改回「主链口径」，并接受它与「改动文件」视图的差异——不要默默用 records 推导却写「同一口径」。
3. **F9 的预算**：用 `usePlan()` 读 `weeklyLimitTokens`，不要自己解析 `localStorage`。
4. **F10 的用户消息**：过滤 `compactSummary` / `isSynthetic` / `isInterrupt`；字数用 `Array.from(text).length`（码点），不要用 `text.length`（UTF-16 单元，emoji 会算 2）。

## 8 最容易做丑的三处（实现者自检表）

1. **星系图变成蜘蛛网**。把模型色限制在 6 个以内 + 中性「其他」；同小时连线只连同泳道相邻两点并设 60 条上限；重叠靠 `--bg-subtle` 描边分隔而不是抖动；时间刻度按窗口收敛。判断标准：把图缩到 50% 看，仍能看出「有几条泳道、哪一段最密」。
2. **成本地形糊成一块渐变**。格间必须留 2px 缝；等高线只连阈值边界、不插值；色阶用 `--cal-*` 而不是透明度；峰值要有常显标注；高对比下每格加描边。判断标准：不看图例也能指出最贵的那一格。
3. **沙盘、名人堂、跑道制造假精确**。实测与假设必须两种画法（中性 vs 彩色）；「假设」「预测」必须出现在柱/线的标签里；无定价、未配对、未设预算一律显式报数并降级；沙盘不持久化；超预算不上红色。判断标准：只看这十张卡，不能让人以为任何一个是账单或承诺。
