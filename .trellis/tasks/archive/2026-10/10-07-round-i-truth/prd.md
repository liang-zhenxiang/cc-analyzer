# PRD：Round I · 证据与层级收口

> 创建于 2026-10-07 · 上一轮：Round H（视觉门面与体验升级，v0.11.0–v0.13.0-beta.1）
> 依据：维护者本轮指令；`.trellis/tasks/round-i-research.md`（竞品调研，带来源 URL）；
> `.trellis/tasks/round-i-design-review.md`（UI/UX 评审，DOM 实测 + 28 张归档截图逐张目验）

## 本轮主题

**把「该说清楚的说清楚」。**

这个项目的**规则**已经比同类干净：令牌纪律、来源徽章、宁可说数据不足也不猜。
本轮的问题不在规则，而在**规则没有被执行到该执行的位置**——
失败没有语义色、错误态把夹具说明和用户绝对路径端到用户面前、
搜索结果显示 ANSI 转义字节、仪表盘 43% 的内容默认在视野之外、
表格的列预算与用户的眼睛打架。

一句话：**资产都有，位置没用。** 本轮把它们放回位置，并补上订阅限额缺失的第二层。

## 背景与证据

### 设计评审的结论（`round-i-design-review.md`）

设计语言站得住；问题集中在四处「语言没被执行」：

1. **语义最强的位置没有语义色**——失败记录与正常记录只差 12px 字重 400→600，
   失败行反而被涂成 `--cat-direct`（与「工具」类别同色）。
2. **三种「未完成」被直接暴露**——ANSI 转义当正文、开发者调试文案与**夹具说明**进 UI、
   **绝对用户路径**进 UI。
3. **表格列预算是错的**——129px 给了一列读不出的 waterfall，摘要列在 305px 处截断；
   筛选一次整表列宽重排（时间列 +30px、摘要列 −117px），行高 38/37/36 三种。
4. **用量总览首屏不成立**——内容 1492px 塞进 852px 的 `main`，
   按项目分布 / 按模型分布 / 活跃时段三块**默认在视野之外**，
   因此归档截图**从来没有拍到过它们**。

评审还附了 **8 条已否证的自测结论**（Y 轴等距正确、X 轴顺序单调、
设置抽屉不透、热力图标签同号、占比条宽度正确、筛选 chip 选中态清晰、
报告空态字色其实过强），**这些一律不许动**。

### 竞品调研的结论（`round-i-research.md`）

- 「限额来得莫名其妙」是压倒性的第一痛（anthropics/claude-code#16157 👍695、#38335 👍476）。
- 「数字不准」是所有用量工具被投诉最多的一条（ccusage 按 👍 排序的 issue 头部几乎全是）
  → 我们的**来源徽章 + 克制披露**是现成的差异化资产，同层竞品没有对位物。
- **Claude 的订阅已是两层限额（5 小时滚动 + 周），我们只做了 5 小时那一层**。
  CCUM#167「Add Weekly Usage and Weekly Reset Day/Time」👍13、CCSeva 的头号卖点都是它。
- 「会话什么时候被压缩、丢了什么」有人明确抱怨且无成熟工具接手（HN 原文引用在手）。
- 决定不做：多机同步 / 云端 / 排行榜（破红线）、代理型观测、多账号、给提问质量打分、
  远程 SSH、毫秒级实时 tail、联网汇率。

## 非目标

- **不做整体重构、不动 `tokens.css` 的字号阶梯**。评审第 12 条（12px/13px 合并）
  会牵动所有组件，**必须单独一轮**，本轮不碰。
- **不做 React 19 迁移**（Issue #19，独立进行）。
- **不做压缩取证**（调研 #2）。它的前提是「压缩记录在真实 JSONL 里有可识别锚点」，
  而验证这一点需要读使用者的真实会话内容——本轮不做，留给下一轮单独立项。
- 不做多机同步 / 云端 / 排行榜 / 代理观测 / 多账号 / 提问质量打分（理由见调研 §5）。
- 不引入第三方 UI 组件库或图标库。

## 红线（本轮特别相关）

- **用户路径视同敏感数据**：`/Users/xxx/...` 这类绝对路径不得出现在界面文案里。
  评审已在错误态里发现一处（`/Users/e2e/.claude/projects`），I2 必须清掉，
  且要有测试拦住它再出现。
- **界面文案不得包含夹具 / 测试说明**：`silent 返回空数组会把夹具错误伪装成成功缺陷`
  这类写给维护者的话已经在 UI 里了，I2 必须清掉。
- 会话内容是不信输入：I1 的 ANSI 处理必须复用既有 `AnsiText` 的白名单机制，
  不得在 `style` 属性里塞正文里的任意字符串。
- 其余红线（`${{ }}` 不直接进 `run:`、capability 不放宽、不提交生成产物、
  release 构建无缓存路径、零遥测）照旧。

## 风险

- **用量总览重构会牵动 3–4 个 CSS Module 与一次信息架构决策**，是本轮成本最高的一项
  → 拆成 I3（布局与图表）与 I4（周窗口）两步，各自可独立验收。
- **周限额没有官方数字**：本机日志里推不出 Anthropic 的官方周重置时刻。
  → 只能做「滚动 7 天消耗（读自日志的精确值）+ 可选预算对照」，
  且必须在界面上说明它不是官方重置窗口。**任何伪造的精确度都不许进界面。**
- **真机 GPU / 字体渲染差异**让截图断言脆弱 → 断言几何关系，不断言像素与颜色。
- **视觉改动会让既有截图全部失效** → I5 统一重出图并由维护者目验。
