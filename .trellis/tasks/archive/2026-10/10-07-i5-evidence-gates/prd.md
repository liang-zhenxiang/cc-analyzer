# PRD：I5 · 证据与门禁：截图覆盖下半屏、e2e 与真机探针扩展

**父任务**：`10-07-round-i-truth` · **优先级**：P1 · **依赖**：I1–I4 全部合并后收尾

## 为什么

设计评审指出一处**方法论缺口**，它比任何一个单点缺陷都更值得修：

> `web/e2e/screenshots.spec.ts` 用 900px 视口、不滚动，而用量页的滚动在 `main` 内部
> （`overflow: auto`，`scrollHeight 1492`）。结果是**归档截图长期只覆盖页面的前 57%**，
> 「按项目分布 / 按模型分布 / 活跃时段」三块从未进入 `docs/screenshots/`，
> **也就从未进入任何一次视觉验收**。

维护者的要求是「真实打开 app 验证，配合截图验证」。**这条链路在用量页上是失效的**——
不是没人看，是看不到。

另外发现一处陈旧证据：

> 归档截图上的版本徽章显示 `v0.10.0`，而代码已经是 `v0.13.0-beta.1`。
> 版本徽章读的是 Rust `package_info()`，e2e 里由 `web/e2e/tauri-mock.ts` 打桩，
> 桩里的版本号没有跟着发版走。

## 需求

### 1. 归档截图覆盖整页（P0）

- 用量页增加「滚动到下半屏」的视图，让三块面板进入归档
- 会话分析页同样检查：报告视图的报告正文现在溢出视口，也要能拍到
- 命名与 `manifest.json` 的既有规则保持一致（视图 × 主题 × 引擎 + 生成 SHA + 脏标记）
- **不改变**既有视图的文件名（README 引用它们）

### 2. 截图桩版本与实际版本对齐（P0）

- e2e 的版本桩必须与 `web/package.json` 的版本一致，
  或由构建时注入，**不得再出现「图上是旧版本」**
- 加一条检查：桩里的版本 ≠ `web/package.json` 的版本时，
  `npm --prefix web test` 或 `./scripts/lint.sh` 失败
  ——这是「防漂移」，不是「这一版修好了」

### 3. e2e 断言扩展

本轮新增/改动的界面都要有端到端断言：

- I1：切换筛选前后逐列宽度差 ≤ 1px；搜索浮层命中摘要无 ESC 字节
- I3：900px 视口不滚动时三块面板标题可见；切 tab 后内容左缘不变
- I4：限额区在选/不选计划两种状态下的读数与说明
- 全部断言都要做**变异验证**（改坏实现 → 必须红）

### 4. 真机取图与几何门禁扩展

`./scripts/gui-test.sh` 的默认视图清单要覆盖本轮的新界面：

- 用量总览的**整页**（下半屏的三块面板）——需要新增几何事实
  （例如「面板标题可见性」或整页 `scrollHeight` 与面板位置的包含关系）
- 搜索浮层（评审发现它有 ANSI 泄漏，但它**从来没进过真机取图清单**）
- 新的限额区
- 既有的不变量（无横向溢出 / 表盘有界且含于卡片 / 记录表末列可达 / 会话行不裁字 /
  ESC 字节为零）必须继续成立，且在新字号档位下重验

**约束**：真机取图走 WebKit 自渲染，`WKWebView.createPDF` **不渲染 `position: fixed`
的浮层**（v0.11.0 已查明）——浮层类视图的证据是**几何探针**，不是截图。
脚本要保留这条提示，别让后人对着截图找浮层。

### 5. 全套重出图与验收

- `SCREENSHOTS=1 npm --prefix web run test:e2e -- screenshots.spec.ts` 重出全部归档图
- 更新 `docs/screenshots/manifest.json`
- 核对 README 双语引用的图仍然存在且正确
- **维护者亲自逐张目验**（浅/深 × 各视图），并亲自跑一次 `./scripts/gui-test.sh --build`

## 非目标

- 不引入像素级截图 diff 框架（几何断言噪声更低、意图更明确，这条选择沿用）
- 不把 `docs/screenshots/` 的生成搬进 CI（产物不该由 CI 写）
- 不改 `release.yml`（本轮无打包改动）

## 验收标准

- [ ] 归档图里**能看到**「按项目分布」「按模型分布」「活跃时段」三块（浅/深各一张）
- [ ] 截图桩版本与 `web/package.json` 一致；不一致时检查会失败
      （**变异验证**：手动改桩版本，检查必须红）
- [ ] 新增的每一条 e2e 断言都做过变异验证
- [ ] `./scripts/gui-test.sh --build` 全绿，且日志里能看到新视图的几何事实
- [ ] README 双语引用的截图路径全部存在（`./scripts/check-readme-parity.sh` 与
      `./scripts/check-screenshots.sh` 通过）
- [ ] 维护者目验记录写进本任务目录

## 入手位置

- `web/e2e/screenshots.spec.ts`、`web/e2e/screenshots-teardown.ts`、`web/e2e/tauri-mock.ts`
- `web/e2e/*.spec.ts`（新增断言）
- `scripts/gui-test.sh`、`scripts/check-screenshots.sh`
- `src-tauri/src/lib.rs` 的 `gui_capture` 模块（几何探针）

## 难度

中。脚本与探针的改动本身不难，**难在两处**：
① 截图脚本的滚动要等视图真的滚到位（否则拍到一半的过渡态）；
② 新几何事实必须能**真的失败**——禁止「永远为真」的断言。

`gui-artifacts/` 下的真机截图是本地取证产物，**不进 git 仓库**
（维护者的既有要求）。别把它加进 `.gitignore` 之外的任何清单。
