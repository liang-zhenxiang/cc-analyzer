# PRD：I3 · 用量总览首屏成立与图表品质

**父任务**：`10-07-round-i-truth` · **优先级**：P1（本轮收益最大的一项）

## 为什么

用量总览是 **README 首图**，也是「吸引别人来用」时用户看到的第一屏。设计评审的实测结论：

> `main` 实测 `scrollHeight 1492 / clientHeight 852`，即**仪表盘 43% 的内容在默认视野之外**，
> 其中包含三块独立面板：「按项目分布」「按模型分布」「活跃时段（7×24）」。
> 归档截图因此**从来没有拍到过它们**——`docs/screenshots/usage-*.png` 是残缺的。

同时可见的那部分里，一张 200px 的空心环形图**在没有选计划时进度弧恒为 0**，
是纯装饰，却占了本页最大的一块黄金位置（实测卡高 350.8px）。

## 需求

### 1. 首屏成立（P0 级收益）

- **硬约束**：1440×900 视口、不滚动时，
  「按项目分布」「按模型分布」「活跃时段」三块的**标题可见**
  （内容可以仍在折叠线以下，但用户要能看见还有东西）
- 达标手段（任选组合，以实测为准）：
  - 环形图缩到 96–120px，四个窗口指标改 **2×2 网格**贴在其右侧
  - 下半区改两列网格：`按项目分布 | 按模型分布` 一行；热力图占满宽
  - 统一卡片内边距（现在 10 / 12 / 13 混用）
- **不得**通过删功能来达标

### 2. 环形图不再是无信息的最大面积元素

- 没选计划时（进度弧恒为 0），环形图必须仍然表达信息，或缩到不喧宾夺主的尺寸
- `消耗 / 速度` 标签不得换行（现在只有它换行，导致该指标**基线不齐**）
- 四个指标改网格排布，label→value 间距**等距**（现在实测 92 / 54 / 53 / 103px 不等）
- `未选计划` 是「无数据」占位，**不得**用 15px/600 与真值同权重

### 3. 「读自日志」降噪

现状：一屏出现 5–6 次，绿色实底 + 绿字 + 绿框，**是全页最抢眼的彩色元素**，
而它标注的信息量≈0。

- 默认渲染成小圆点 / 弱化形态，或用一次性的「数据来源：本机日志」表达整组
- **保留** hover 可读的来源说明（这是差异化资产，不是要删掉它，是要它别抢戏）

### 4. KPI 层级

- 数值是主角：`--fs-lg` / 600；chip 降到 11px 圆点或移到标签行
- 「估算成本」的三层免责（列头「非账单」+ chip「估算」+「快照日期」）收成
  **卡片底部的跨列 footnote**，不再进列内
- 消除「chip 决定整卡高度、前三列各留 60px 死白」

### 5. 图表体例统一

- **坐标轴刻度**：`axisTicks(niceAxisMax(...), 3)` 现在产出 `200K / 133.3K / 66.7K / 0`
  这类非整数刻度 → 改为取整（如 `0 / 50K / 100K / 150K / 200K`）。
  **注意**：评审已否证「刻度不等距」，等距是对的，**只改标签取值**
- **日期标签**：`9-8` 这种裸 M-D 且形如比分 → 统一体例（`9/8` 或 `9月8日`），
  并与另一图的 `HH:MM` 体例区分清楚
- **柱形填充**：柱只有 10% 填充 + 1px 描边，浅色下几乎只剩描边、读不出面积
  → 提高填充可见度（可调整 `--chart-*-soft` 的 alpha；这是**本轮唯一允许改的既有令牌**，
  且必须**同时**校验浅/深两套主题下的对比度，并在 PR 里给出数值）
- **0 值柱**渲染 1–2px 短桩而不是完全不可见
- **稀疏数据**：近 30 天只有 2 天有数据时，左侧 85% 空场 → 给出可接受的呈现
  （如按有数据的天数自适应，或明确标注空档）
- **近几个窗口**：X 轴是等距排布而真实时间间隔不等（3h/7h/0h/5m/10m）
  → 要么换成按时间比例的轴，要么在轴上给一句「窗口」说明；
  **柱间距不得是柱宽的 2 倍**；6 根柱里 3 根高 0 时的呈现要交代清楚

### 6. 热力图

- 补**色阶图例**（少→多，4 档方块）——没有图例的热力图等于没有刻度
- 空格子去掉描边，只用填充（现在 168 格同时有填充和描边，空/非空双重编码）
- 标题 `活跃时段（7×24）` 是规格不是标签 → 改成人话（如「活跃时段（周 × 小时）」）

### 7. 原始标识符不再直接当标签

- `-repo-usage-days`（目录名）→ 新增 `formatProjectPath()`：显示末段 + title 全路径
- `claude-sonnet-4-5-20250929` → 新增 `formatModelId()`：显示 `Sonnet 4.5`，日期进 title
- 三处共用（图表类别标签、搜索分组标题、侧栏 meta）——**一份实现**

### 8. 容器宽度一致

用量页居中 1080px，分析页全幅 12–1428px，**切 tab 时内容整体横跳 168px**
→ 两页统一容器宽度（或至少保持同一左缘）

## 非目标

- 不做「成本归因 / 效率建议」（调研 #4，需要不可证伪的分类，违背项目性格）
- 不做 Wrapped / 分享卡（调研 #7，本轮不做）
- 不动字号阶梯（评审第 12 条，单独一轮）
- 不新增数据源、不新增 Tauri 命令
