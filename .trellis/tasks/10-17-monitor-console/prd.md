# 监控台：把「外部仪表盘」做成自带仪表盘

## Goal

`实时监控 → 外部仪表盘` 一直是一个指向 `localhost:8090` 的 iframe，而那个服务
**不在本仓库**。多数人点进去只看到「未连接」，这一档等于空的。

这一轮把它**实现出来**：新增一个自带的原生**监控台**，不依赖任何外部服务、
不新增网络请求，复用已有的本地日志与数据层。原来的外部仪表盘 iframe 保留为
第三个子视图——已经在自己跑那套服务的人行为一字不变。

用户价值：这是唯一一个「一屏看完今天」的视图。脉搏回答「此刻」，用量总览回答
「区间」，监控台回答**「今天这一天，谁在烧、烧在哪个项目、出过什么事」**。

## Background（已核实的事实）

- **现状**：`MonitorPage` 的分段控件是 `脉搏 | 外部仪表盘`；`ExternalDashboard`
  是「显式打开 + 探测 + iframe」的状态机（#55）。外部服务不在本仓库。
- **数据已经全部在手**：`usePulseFeed()` 的 `PulseSnapshot` 带 `inputs`
  （`UsageSessionInput[]`，含 `records` / `compactEvents` / `toolCalls`）、
  `rows`（活跃会话）、`latest`、`now`。监控台的每一个数都能从它折出来，**零新增 I/O 通道**。
- **口径必须复用**：token 走 `totalsSum`、天边界走 `dayStartOf` / `addLocalDays`、
  5 小时窗口走 `billingReadoutsOf`、预测走 `predictLimitReach`、
  标题走 `fallbackSessionTitle`。监控台不自带第二套数学。
- **节流与可见性已经解决**：`usePulseFeed` 是 setTimeout 链、慢拍自适应、
  隐藏即停、失败保留旧读数。监控台与脉搏各持一个实例，但解析缓存
  （`sharedSessionParseCache`）共享，切档不重复付费。
- **日历那轮的教训仍然有效**：同一个概念不要在两个窗口下同屏出现。监控台只做
  **今天（本地自然日）**，不做 7/30/90 天、不做滚动 365 天。

## Requirements

**R1 结构。** `实时监控` 的分段控件变成三项：`脉搏 | 监控台 | 外部仪表盘`。
默认仍是「脉搏」（既有行为不变）；「外部仪表盘」保持 #55 的显式打开、探测重试、
`enter-float` 消息协议、文案，一字不动。

**R2 零新增数据通道。** 监控台吃 `usePulseFeed()` 的同一份 `PulseSnapshot`，
不新增 Tauri 命令、不新增 `Bridges` 接口、不新增网络请求、不加权限。

**R3 顶部读数带（4 枚）。**
- **本窗口已用**：与脉搏 / 用量总览**同一个** `billingReadoutsOf` 的当前块，
  数字必须逐位相等；带「距关闭还剩」。
- **今天**：本地自然日（`dayStartOf(now)` 起）的四类 token 之和。
- **活跃会话**：`rows.length`（最近 5 小时有新记录）。
- **今天压缩**：本地自然日内 `compactEvents` 的条数。

**R4 项目热度榜。** 按项目聚合：**近 15 分钟实测速率**（token/小时，降序）、
今天 token 总量、活跃会话数。每行一条速率条（长度 = 相对榜首的比例）。点一行
**筛选右侧事件流**（再点取消）。空项目不显示。

**R5 24 小时活动带。** 本地自然日 24 个小时桶，每桶四类 token 之和；**当前这一小时
未走完**，用与脉搏「进行中」同一套形状语言（斜纹填充 + 虚线轮廓），高度是实测值、
不外推。鼠标悬停给「HH 点 · N token」；`role="img"` 带文字摘要。

**R6 事件流。** 最近 12 条跨会话事件，时间倒序，三类：
- **压缩**（`compactEvents`）：显示触发方式（自动 / 手动）与 `preTokens`（未知就写未知）；
- **错误**（`record.isError`）：显示工具名与脱敏后的首行（≤80 字符）；
- **会话开始**（每个会话的首条有效记录）：显示标题。

每条带时间（`HH:mm`）、项目、会话标题；点一条**打开那个会话**（与用量页同一握手）。
顶部有筛选（全部 / 压缩 / 错误 / 会话开始）；筛选与项目筛选可叠加。

**R7 四态。** 加载（骨架，不出现假 0）/ 空（一条事实行）/ 错误（沿用 `ErrorState`）/
过期（保留旧读数 + 「上次更新 … · 本次读取失败」）——与脉搏同一套语言。

**R8 视觉。** 界面美观度第一：由 UI/UX 设计师 agent 出规格，主会话独立评审后实现。
浅 / 深 / 高对比度三档、字号 130% 与 960px 窄窗无横向溢出；**目标零新增颜色令牌**；
错误用 `--danger`、进行中的小时用形状而不是透明度。

**R9 无障碍。** 两个图表 `role="img"` + 文字摘要；项目行是按钮；事件是按钮；
键盘可达；筛选是分段控件（既有组件）。

**R10 性能。** `snapshot` 不变时不重算（`useMemo`）；在合成 ≥300 会话夹具上量一次
单次重算耗时，写进 PR；目标 < 100 ms。

**R11 测试（全自动）。**
- 单元：`consoleModel.ts` 的每个纯函数——15 分钟窗口边界、24h 桶（当前小时 partial）、
  项目聚合排序与并列、事件流三类与 12 条上限、错误文本脱敏、空输入。
- 组件：四态、筛选叠加、点项目筛选事件流、点事件回调、图表有无 partial。
- 端到端（Chromium + WebKit）：切到监控台看到确定值、点事件打开会话、点项目筛选、
  与脉搏的 5 小时数字一致。
- 截图：浅 / 深入基线（`docs/screenshots/views.json` 一处）。
- 真机 GUI：`gui-test.sh` 加监控台步骤与探针（卡片数、无横向溢出、事件行）。

**R12 文档。** README 中英、`docs/USAGE.md`、`docs/ARCHITECTURE.md`、
`CHANGELOG.md` 的 `[Unreleased]`（中文）。

## 不做

- **不做本地 HTTP 服务**：那会让会话标题/项目名出现在一个任何本机进程都能读的端口上，
  且要在 Rust 里重写一套数据层。监控台在应用内，零新增网络面。
- **不做 7/30/90 天**：那是用量总览的窗口；监控台固定「今天」。
- **不做用户自定义布局 / 拖拽卡片**。
- **不删外部仪表盘**：已有人在用，#55 的行为保持不变。
- **不做通知 / 声音 / 自动弹出**。

## 验收标准

- [ ] 分段控件三项，默认脉搏；外部仪表盘行为不变（#55 的既有断言全绿）
- [ ] 监控台的「本窗口已用」与脉搏、用量总览逐位相等
- [ ] 24h 活动带的当前小时标 `partial`，且不外推
- [ ] 项目榜按近 15 分钟速率降序；点行筛选事件流，再点取消
- [ ] 事件流三类齐全、上限 12、时间倒序、点一条打开对应会话
- [ ] 错误预览 ≤80 字符且不含绝对路径
- [ ] 四态各一例；过期态保留旧读数
- [ ] 130% / HC / 960px 无横向溢出（几何断言）
- [ ] 截图基线 `monitor-console` 浅深 × 两引擎
- [ ] 真机门禁全绿并亲自看截图
- [ ] 性能 < 100 ms（≥300 会话合成夹具）
- [ ] lint / 单测 / build / e2e / cargo 四件套 / 真机门禁全绿
