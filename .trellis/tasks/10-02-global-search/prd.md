# PRD：全局搜索（命令面板）

> 对应 Issue #69 · 创建于 2026-10-02 · Round E
> 依据：`.trellis/workspace/liangyuxiang/research-competitors.md` 建议 7（CCHV + opcode）

## 背景

跨项目、跨会话找「上次那段对话」目前只能靠记性。竞品里 CCHV 与 opcode 都把全局
搜索当核心能力，而 CCHV 的高频差评恰恰是**搜索结果与侧栏联动断裂**——点结果
跳不到对应会话。本轮把搜索做成命令面板（⌘K），并把「点击即定位」当验收重点。

## 用户故事

- 作为用户，我按 ⌘K（或点顶栏搜索按钮）唤起面板，输入关键词，立刻看到
  跨全部项目的匹配消息，按 项目 → 会话 分组。
- 我用 ↑↓ 选择、Enter 跳转：应用切到「会话分析」、打开那个会话、
  高亮那条记录并展开详情——全程不需要再找一遍。
- 匹配词在结果里高亮，一眼看出为什么命中。
- 索引在后台渐进构建（复用会话解析缓存），构建中有进度提示，
  二次唤起即时可用。

## 功能需求

1. **索引层**（纯逻辑 + 模块级单例）：消费已解析会话，收集 user/assistant
   记录的文本（工具调用名不进 v1 索引），小写归一；查询为大小写不敏感
   子串匹配；结果按项目分组、组内会话按新→旧、记录按时间序。
2. **命令面板 UI**：居中浮层（复用浮层语言：--shadow-md、--r-lg 台阶），
   输入框 + 分组结果列表 + 匹配片段高亮；↑↓/Enter/Esc 键盘流；
   空态区分「索引构建中 N/M」「无匹配」「请输入关键词」。
3. **跳转联动**：Enter/点击 → 关面板 → 切会话分析页 → 打开会话 →
   高亮记录并进详情面板（复用既有 revealRecord 链路）。
4. **入口**：顶栏搜索 IconButton（可访问名「全局搜索」）+ ⌘K / Ctrl+K 快捷键。

## 约束

- 零新增运行时依赖；纯内存索引不落盘（隐私红线：搜索历史不留痕）
- 复用 sessionParseCache 的共享单例，不重复解析、不重复占内存
- 既有测试全绿；新交互（快捷键、面板键盘流、跳转联动）三层测试覆盖

## 非目标

- 模糊匹配/拼音/正则（v1 子串即可，先解决「找不到」再优化「找得快」）
- 工具调用与工具结果的全文检索（后续）
- 搜索历史持久化

## 验收标准

- [x] ⌘K 与顶栏按钮都能唤起/关闭面板，Esc 关闭，焦点管理正确
- [x] 夹具关键词命中跨两个项目的消息，分组与排序正确
- [x] Enter 跳转后：会话已选中、目标记录高亮且详情面板可见（e2e 断言）
- [x] 单测：索引构建/查询/分组/边界（空文本、纯符号、大小写）
- [x] E2E 双引擎 + GUI 真机全绿；CHANGELOG 中文条目；USAGE 文档更新
