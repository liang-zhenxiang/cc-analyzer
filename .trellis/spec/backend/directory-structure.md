# Backend Directory Structure

> What lives in `src-tauri/`, what is generated, and what must be committed.

---

## Layout

| Path | Role |
|------|------|
| `src-tauri/src/main.rs` | Binary entry. `windows_subsystem = "windows"` under `not(debug_assertions)`, then `cc_analyzer::run()`. Nothing else belongs here. |
| `src-tauri/src/lib.rs` | Every command, the `float` inline plugin, and `pub fn run()`. **One flat file — there is no `commands/` module tree.** |
| `src-tauri/build.rs` | Declares the command manifest the ACL is generated from. See below. |
| `src-tauri/tauri.conf.json` | Window, bundle, `app.security` config. Source of truth for packaging. |
| `src-tauri/capabilities/default.json` | The single capability granting commands to window `main`. |
| `src-tauri/permissions/autogenerated/*.toml` | 13 permission files, **committed to git** despite the `DO NOT EDIT` header. |
| `src-tauri/gen/` | Tauri-generated schemas. **Gitignored** — never commit. |
| `src-tauri/icons/` | Bundle icons referenced from `tauri.conf.json`. |

The crate is `cc-analyzer` (lib target `cc_analyzer`), edition 2021,
`rust-version = "1.77"`, version kept in sync with `web/package.json` and
`tauri.conf.json` (AGENTS.md §4).

---

## Code Organization Inside `lib.rs`

Everything is top-level in one file, ordered roughly: state structs, IPC
payload structs, shared helpers, commands, then plugins/bootstrap.

- **State**: `ProcState` (holds `StdMutex<HashMap<String, oneshot::Sender<()>>>`)
  is registered once via `.manage(ProcState::default())` in `run()` and reached
  from commands through `tauri::State<'_, ProcState>`.
- **Payload structs**: `DirEntry`, `StatInfo`, `RunLinesResult`, `ExecTextResult`
  — all `#[derive(Serialize)]`, all defined next to the command that returns
  them. Their TS mirrors live in `web/src/api/types.ts`.
- **Shared helpers**: `io_error`, `modified_ms`, `string_from_head`,
  `child_command`. Keep helpers small, private, and next to their callers.
- **Commands**: 13 `#[tauri::command]` functions (12 sync/async in the app
  manifest, plus `cancel_lines` — see the warning below).

### Inlined plugins

`mod float_plugin` (lib.rs:401) is the pattern for plugin-shaped features: a
private module with its own `RestoreState`, its own `#[tauri::command] fn enter`
/ `exit`, and a `pub fn init() -> TauriPlugin<Wry>` built with
`tauri::plugin::Builder::new("float")`. It is registered with
`.plugin(float_plugin::init())` in `run()` and invoked from JS as
`plugin:float|enter`. Add a plugin only when the feature has its own state and
lifecycle; otherwise add a plain command.

### Bootstrap in `run()`

`run()` is the only place that wires things: `.plugin(...)`, `.manage(...)`,
`.invoke_handler(tauri::generate_handler![...])`, `.setup(...)` (native menu +
`app_data_dir` creation), then `.run(tauri::generate_context!())`.

## `build.rs` Is the Source of Truth for the ACL

```rust
.app_manifest(tauri_build::AppManifest::new().commands(&[ ... ]))
```

`tauri-build` writes `allow-<command>` / `deny-<command>` entries into
`src-tauri/permissions/autogenerated/<command>.toml` for exactly the commands
listed here (see `tauri-utils::acl::build::autogenerate_command_permissions`).
A command missing from this array gets **no autogenerated permission file**, so
its `allow-…` entry in `capabilities/default.json` cannot resolve.

> **Current gap**: `cancel_lines` is absent from the `app_manifest.commands`
> list in `build.rs`, yet `cancel_lines.toml` exists and is committed. The
> command works today only because `tauri-build` globs the whole
> `permissions/autogenerated/` directory and never deletes stale files. Any
> cleanup of that directory (it has a `DO NOT EDIT` header and sits next to the
> gitignored `gen/`) would break `allow-cancel-lines`. Add `"cancel_lines"` to
> `build.rs` when you next touch it.

## Generated vs. Source — Commit Rules

| Directory | Committed? | Why |
|-----------|-----------|-----|
| `src-tauri/gen/` | No (`.gitignore`) | Regenerated every build. |
| `src-tauri/permissions/autogenerated/` | **Yes** | `tauri-build` reads it back when resolving capabilities; deleting it orphans any permission not in `build.rs`. |
| `src-tauri/target/` | No (`.gitignore`) | Build output. |
| `dist-arm64/`, `dist-intel/`, `dist-windows/` | No (`.gitignore`) | Bundle output. |

## Anti-Patterns

- Splitting commands into a new module tree "for tidiness" — the flat file is
  intentional; a 545-line file is cheaper than a layer that adds indirection.
- Adding a `utils.rs` / `error.rs` module for helpers used by two commands.
- Moving IPC payload structs into a shared types module while `web/src/api/types.ts`
  stays hand-written — the pair must stay trivially diffable.
- Committing anything under `src-tauri/gen/`, `target/`, or `dist-*/`.
